Portofolio Proyek:

Semua proyek yang saya kembangkan didasari oleh rasa ingin tahu dan dipelajari secara mandiri. Berikut adalah beberapa di antaranya:

1. 1cak & Otakudesu Unofficial API

Deskripsi: Dua proyek web scraping yang berfungsi sebagai API tidak resmi untuk mengambil data dari situs 1cak dan Otakudesu. Proyek ini menunjukkan kemampuan dalam rekayasa balik (reverse engineering) dan pembuatan API.

Teknologi: Go, Fiber (Web Framework), Colly (Scraping Framework).

Tautan Repositori:

  • 1cak Unofficial API
  • Otakudesu Unofficial API

2. Go WhatsApp Bot

Deskripsi: Sebuah kerangka bot WhatsApp yang dibangun menggunakan Go, memanfaatkan library Whatsmeow. Proyek ini adalah eksplorasi dalam otomatisasi dan interaksi dengan platform pesan instan.

Teknologi: Go, Whatsmeow.

Tautan Repositori: Go WhatsApp Bot

3. Anime-Fasthtml

Deskripsi: Proyek web yang mengimplementasikan FastHTML, sebuah library untuk membangun antarmuka web reaktif tanpa menulis JavaScript secara manual.

Teknologi: Python, FastHTML, TailwindCSS.

Tautan Repositori: Anime-Fasthtml
